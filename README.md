# EngineEditor

GameEngineを使用するゲーム制作エディターです。

## 開発目標

- シーン編集
- ゲームオブジェクト編集
- インスペクター
- アセットブラウザー
- レベル編集
- ゲームプレビュー
- エディター拡張機構

## 技術方針

Windows / WPF / C# / ネイティブエンジン連携

## 依存関係

GameEngine SDKを使用します。

統合開発時はEngineWorkspaceで管理するGameEngineを参照し、依存関係の重複を避けます。
